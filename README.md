Smart Hostel Room Allocation System

A React-based solution designed to manage hostel room inventory and intelligently allocate rooms to students based on capacity and specific facility requirements.

🛠️ Tech Stack

Frontend: React.js

Styling: Tailwind CSS

Icons: Lucide React

Persistence: Browser LocalStorage

📋 Features to be Implemented

- Room Management (Add Room Form)

- Room Inventory View (List & Search)

- Smart Allocation Algorithm (Smallest possible room selection)

- Persistence via LocalStorage
